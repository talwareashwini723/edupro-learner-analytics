# EduPro Learner Demographics and Course Enrollment Analysis

## Overview

This project analyzes learner demographics and course enrollment
behavior on the EduPro online learning platform.

## Objectives

- Analyze learner age distribution
- Analyze gender participation
- Identify popular course categories
- Analyze course-level preferences
- Study demographic-based course preferences

## Technologies

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## Dashboard Features

- Learner demographic overview
- Age distribution
- Gender distribution
- Course category popularity
- Course level analysis
- Age × category analysis
- Interactive filters

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
